网关与沙箱参数索引

查询 Gateway 公共字段、Docker、Kubernetes、E2B 与沙箱运行时变量的默认值和影响。

本页内容
  • 网关公共设置
  • Docker 设置
  • Kubernetes 设置
  • E2B 设置
  • 沙箱运行时变量

修改网关配置后重启对应服务，并用新建测试环境验证。选用与 driver 一致的后端段。时间为秒，内存为 MiB，磁盘为 GiB。Grasp 平台字段在配置项索引，连接步骤见网关与预览。

网关公共设置

YAML 路径 环境变量 默认值 用途
YAML 路径driver 环境变量SBGW_DRIVER 默认值docker 用途docker / kubernetes / e2b；环境变量与文件不能冲突
YAML 路径server.listen 环境变量SBGW_LISTEN 默认值:8080 用途网关 API 监听
YAML 路径server.finalizeTimeoutSeconds 环境变量SBGW_FINALIZE_TIMEOUT_SEC 默认值1200 用途创建/重装就绪期限
YAML 路径database.driver 环境变量SBGW_DB_DRIVER 默认值sqlite 用途sqlite、mysql 或 postgres
YAML 路径database.path 环境变量SBGW_DB_PATH 默认值gateway.db 用途SQLite 持久化文件
YAML 路径database.dsn 环境变量SBGW_DB_DSN 默认值空 用途PostgreSQL 必填。MySQL 优先使用 DSN，也可使用下方分项
YAML 路径database.host / database.port 环境变量SBGW_DB_HOST / SBGW_DB_PORT 默认值空 / 0（连接时用 3306） 用途MySQL 主机和端口
YAML 路径database.user / database.password / database.name 环境变量SBGW_DB_USER / SBGW_DB_PASSWORD / SBGW_DB_NAME 默认值空 用途MySQL 账号及数据库
YAML 路径database.params 环境变量— 默认值空 用途MySQL 默认补 charset=utf8mb4&parseTime=True&loc=Local
YAML 路径auth.apiKeys 环境变量SBGW_API_KEYS 默认值[] 用途Bearer key，环境变量用逗号分隔；空禁用 v1 鉴权且不能使用 v2 transport
YAML 路径orphanGC.enabled 环境变量SBGW_ORPHAN_GC_ENABLED 默认值false 用途清理无数据库记录的本部署工作负载
YAML 路径orphanGC.intervalSeconds 环境变量SBGW_ORPHAN_GC_INTERVAL_SEC 默认值300 用途扫描间隔
YAML 路径orphanGC.minAgeSeconds 环境变量SBGW_ORPHAN_GC_MIN_AGE_SEC 默认值600 用途最小清理年龄；0 无年龄限制
YAML 路径ports.session / ports.codeServer / ports.ssh 环境变量— 默认值8765 / 8744 / 22 用途会话、IDE、SSH 端口
YAML 路径ports.cdp / ports.novnc 环境变量— 默认值9222 / 6080 用途内部端口，不发布到 Docker 主机 / K8s LB
YAML 路径ports.app 环境变量— 默认值见各后端示例 用途额外应用端口
YAML 路径— 环境变量SBGW_LOG_LEVEL 默认值info 用途网关日志级别，仅环境变量
YAML 路径— 环境变量SBGW_LOG_PRETTY 默认值false 用途网关日志人类可读格式，仅环境变量

Docker 设置

docker 字段 环境变量 默认值 用途
docker 字段image 环境变量SBGW_DOCKER_IMAGE 默认值universal-sandbox:local 用途真实 OCI 镜像
docker 字段bindIP 环境变量SBGW_DOCKER_BIND_IP 默认值127.0.0.1 用途发布端口的宿主地址
docker 字段network 环境变量SBGW_DOCKER_NETWORK 默认值空 用途Docker 网络
docker 字段namePrefix / shmSize 环境变量— 默认值sbx- / 1g 用途容器名称前缀及共享内存
docker 字段resources.default 环境变量— 默认值CPU 0、memory 0、disk 0 用途请求省略资源时采用；0 表示不限制；字段为 cpuCores/memoryMB/diskGi
docker 字段resources.max 环境变量— 默认值CPU 8、memory 16384、disk 500 用途API 请求上限；不等于 Docker 磁盘配额
docker 字段profiles 环境变量— 默认值{} 用途可选 名称: {image: OCI镜像}，供 Grasp 命名连接选择

Kubernetes 设置

kubernetes 字段 环境变量 默认值 用途
kubernetes 字段image 环境变量SBGW_K8S_IMAGE 默认值universal-sandbox:local 用途节点可获取的 OCI 镜像
kubernetes 字段inCluster 环境变量SBGW_K8S_IN_CLUSTER 默认值false 用途使用 Pod service account
kubernetes 字段kubeconfig 环境变量SBGW_K8S_KUBECONFIG 默认值空 用途留空使用标准 kubeconfig / in-cluster 发现
kubernetes 字段namespace 环境变量SBGW_K8S_NAMESPACE 默认值sandboxes 用途沙箱所在 namespace
kubernetes 字段namePrefix 环境变量— 默认值sbx- 用途工作负载名称前缀
kubernetes 字段storageClass 环境变量SBGW_K8S_STORAGE_CLASS 默认值空 用途使用集群默认 StorageClass
kubernetes 字段pvcAnnotations 环境变量— 默认值{} 用途新建 PVC 的注解
kubernetes 字段imagePullSecret 环境变量— 默认值空 用途私有镜像仓库 Secret
kubernetes 字段imagePullPolicy 环境变量SBGW_K8S_IMAGE_PULL_POLICY 默认值IfNotPresent 用途Always / IfNotPresent / Never
kubernetes 字段enableLoadBalancer 环境变量SBGW_K8S_ENABLE_LB 默认值true 用途是否创建公开端口的 LB Service
kubernetes 字段resources.default / resources.max 环境变量— 默认值2/4096/25 / 8/16384/500 用途CPU、内存、PVC 容量；字段为 cpuCores/memoryMB/diskGi
kubernetes 字段cpuRequestCores / memoryRequestMB 环境变量— 默认值0.25 / 512 用途调度 request，固定值优先；填 0 才使用对应比例
kubernetes 字段cpuRequestRatio / memoryRequestRatio 环境变量— 默认值0.25 / 0.25 用途request = limit × ratio，范围 (0,1]，驱动应用最小 request 保护
kubernetes 字段profiles 环境变量— 默认值{} 用途可选环境名到 OCI 镜像映射

E2B 设置

e2b 字段 环境变量 默认值 / 要求 含义
e2b 字段apiURL 环境变量SBGW_E2B_API_URL 默认值 / 要求必填，无默认 含义你的 E2B 控制 API；自建填写自建地址，云服务填写 https://api.e2b.app
e2b 字段sandboxURL 环境变量SBGW_E2B_SANDBOX_URL 默认值 / 要求空 含义自建沙箱代理来源；留空使用 provider 返回的每个沙箱域名，返回为空则报错
e2b 字段apiKey 环境变量SBGW_E2B_API_KEY 默认值 / 要求必填 含义E2B API key，建议仅环境变量
e2b 字段ownerID 环境变量SBGW_E2B_OWNER_ID 默认值 / 要求必填 含义稳定、唯一的部署标识，限制管理范围
e2b 字段stateDir 环境变量SBGW_E2B_STATE_DIR 默认值 / 要求必填，绝对路径且不能为 / 含义私有连接恢复记录，须持久化
e2b 字段bootTimeoutSeconds 环境变量SBGW_E2B_BOOT_TIMEOUT_SEC 默认值 / 要求600 含义guest 启动及私有连接准备期限
e2b 字段leaseSeconds 环境变量SBGW_E2B_LEASE_SEC 默认值 / 要求3600 含义请求的 provider 租约，至少 30
e2b 字段renewIntervalSeconds 环境变量SBGW_E2B_RENEW_INTERVAL_SEC 默认值 / 要求300 含义必须大于 0 且小于租约一半
e2b 字段autoPause 环境变量SBGW_E2B_AUTO_PAUSE 默认值 / 要求true 含义新 guest 到期自动暂停；显式删除仍销毁
e2b 字段templates 环境变量— 默认值 / 要求必填，无默认模板 含义名称 → {templateID,cpuCores,memoryMB,diskGi}
e2b 字段defaultTemplate 环境变量— 默认值 / 要求单模板自动选择，多模板必填 含义必须是 templates 中的名称

沙箱运行时变量

箱内变量 独立运行时默认值 Grasp 管理沙箱时的来源 / 用途
箱内变量GRASP_RUNTIME_URL 独立运行时默认值无，启动必填 Grasp 管理沙箱时的来源 / 用途Grasp 自动提供运行时包下载地址
箱内变量SANDBOX_INJECT / SANDBOX_INJECT_HEADERS 独立运行时默认值空 Grasp 管理沙箱时的来源 / 用途Grasp 提供配置包与有作用域的下载凭据
箱内变量WORKSPACE_DIR 独立运行时默认值/root/workspace Grasp 管理沙箱时的来源 / 用途沙箱内的代码目录；与 Grasp 的 sandbox.work_dir 不同
箱内变量ROOT_PASSWORD 独立运行时默认值toor Grasp 管理沙箱时的来源 / 用途Grasp 为沙箱注入密码；不要按独立脚本默认值推断平台沙箱密码
箱内变量SSH_KEY 独立运行时默认值空 Grasp 管理沙箱时的来源 / 用途可选 SSH 公钥
箱内变量CODE_SERVER_PORT 独立运行时默认值8744 Grasp 管理沙箱时的来源 / 用途IDE 监听端口
箱内变量AGENT_PROVIDER 独立运行时默认值cursor Grasp 管理沙箱时的来源 / 用途Grasp 按所选编码工具设置，与 gateway driver 无关
箱内变量ACP_BRIDGE_PORT 独立运行时默认值8765 Grasp 管理沙箱时的来源 / 用途Agent 会话服务端口
箱内变量ACP_BRIDGE_PASSWORD 独立运行时默认值空 Grasp 管理沙箱时的来源 / 用途Grasp 创建时注入会话鉴权口令
箱内变量SKIP_INNER_DOCKER 独立运行时默认值按 0 处理，启动内层 Docker Grasp 管理沙箱时的来源 / 用途设置 1 时跳过内层 dockerd
箱内变量INNER_DOCKER_STORAGE_DRIVER 独立运行时默认值vfs Grasp 管理沙箱时的来源 / 用途内层 Docker 存储驱动
箱内变量PREVIEW_DIRECT / PREVIEW_PORT 独立运行时默认值空 Grasp 管理沙箱时的来源 / 用途直连预览注入开关与应用端口，由平台预览配置决定
