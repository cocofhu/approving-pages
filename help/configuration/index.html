./start.sh dev -d      # 源码 + HMR

镜像 tag / digest、网关与沙箱相关变量见 .env.example。Agent 侧 API key、GITHUB_* / GITLAB_* / SSH 等放在 Agent meta env（值可引用 ${vars.<name>}）。
