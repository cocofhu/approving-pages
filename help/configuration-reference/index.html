Gateway、模板与沙箱内部选项

按后端浏览网关参数索引。使用完整部署参数参考查看 Docker、Kubernetes、E2B、Gateway 和沙箱内部字段。用网关配置指南选择连接方式和预览策略。

Grasp 服务端字段

这张表从服务端生成的配置参考引入，包含环境变量、YAML 路径、类型、默认值、敏感性和用途。发布栈、设置保存值和 Gateway 默认值可能影响实际值，可根据覆盖顺序判断。

环境变量 YAML 路径 类型 默认值 敏感性 用途
环境变量GRASP_PORT YAML 路径server.port 类型integer 默认值8080 敏感性公开 用途HTTP 监听端口
环境变量GRASP_DEPLOYMENT_MODE YAML 路径server.deployment_mode 类型string 默认值development 敏感性公开 用途部署信任边界。local-demo 仅限 loopback
环境变量GRASP_MCP_ADVERTISE YAML 路径server.mcp_advertise 类型URL 默认值derived 敏感性公开 用途沙箱回连 grasp-tool MCP 的 API 基址
环境变量GRASP_PUBLIC_ADVERTISE YAML 路径server.public_advertise 类型URL 默认值derived 敏感性公开 用途浏览器预览代理的公开基址（不用于门禁分享铸造）
环境变量GRASP_FRAME_ANCESTORS YAML 路径server.frame_ancestors 类型origin list 默认值未设置 敏感性公开 用途允许用 iframe 嵌入工作区页面的来源（空格或逗号分隔，如 https://portal.example.com）。留空禁止嵌入
环境变量GRASP_PREVIEW_EXPOSE_STRATEGY YAML 路径preview.expose.strategy 类型enum 默认值auto 敏感性公开 用途全局默认预览暴露策略，auto、subdomain 或 none（direct 仅限直连网关在 YAML 连接级配置）
环境变量GRASP_PREVIEW_EXPOSE_SUBDOMAIN_BASE_URL YAML 路径preview.expose.subdomain.base_url 类型URL 默认值未设置 敏感性公开 用途通配子域名预览基址（HTTP(S) DNS origin，拒绝 IP。production 要求 https 且与平台不同根域）
环境变量GRASP_DB YAML 路径database.path 类型path 默认值grasp.db 敏感性公开 用途SQLite 数据库文件
环境变量GRASP_DB_DRIVER YAML 路径database.driver 类型enum 默认值sqlite 敏感性公开 用途数据库驱动，支持 sqlite、mysql 和 postgres
环境变量GRASP_DB_DSN YAML 路径database.dsn 类型string 默认值未设置 敏感性敏感 用途MySQL 或 PostgreSQL 连接串
环境变量GRASP_PROFILES_ROOT YAML 路径engine.profiles_root 类型path 默认值data/profiles 敏感性公开 用途Agent profile 根目录
环境变量GRASP_NODE_AUTO_RETRY YAML 路径engine.node_auto_retry_max 类型integer 默认值3 敏感性公开 用途节点自动重试上限
环境变量GRASP_SANDBOX_IMAGE YAML 路径sandbox.image 类型image 默认值未设置 敏感性公开 用途已废弃并忽略（含 sandbox.images.* 与 GRASP_SANDBOX_IMAGE_*），沙箱镜像由 sandbox-gateway 配置（docker/kubernetes 的 image 或 profiles，E2B 的 defaultTemplate 或 templates），Grasp 通过 GET /api/v1/capabilities 读取
环境变量GRASP_SANDBOX_GATEWAY_URL YAML 路径sandbox.gateway_url 类型URL 默认值http://127.0.0.1:8899 敏感性公开 用途sandbox-gateway 控制面地址
环境变量GRASP_SANDBOX_GATEWAY_API_KEY YAML 路径sandbox.gateway_api_key 类型string 默认值未设置 敏感性敏感 用途gateway Bearer token
环境变量GRASP_SANDBOX_GATEWAY_TRANSPORT YAML 路径sandbox.gateway_transport 类型enum 默认值direct 敏感性公开 用途沙箱连接方式，direct 直连或 gateway 认证通道。gateway 要求 API key，预览按 preview.expose / 连接级 preview_expose 策略暴露
环境变量GRASP_SANDBOX_DEFAULT_GATEWAY YAML 路径sandbox.default_gateway 类型string 默认值未设置 敏感性公开 用途新沙箱使用的命名网关。已有沙箱保持原绑定
环境变量GRASP_SANDBOX_PRIVATE_ENDPOINTS YAML 路径sandbox.private_endpoints 类型boolean 默认值false 敏感性公开 用途显式标记沙箱端点仅服务端可达。仅影响 preview.expose auto 展开与传统私有启动等待，不再因 gateway 通道自动覆盖
环境变量GRASP_OPENCODE_CATALOG_URL YAML 路径sandbox.opencode_catalog_url 类型URL 默认值https://models.dev/api.json 敏感性公开 用途OpenCode 模型目录地址。出网受限时改指镜像
环境变量GRASP_SANDBOX_ENV YAML 路径sandbox.env 类型key-value list 默认值未设置 敏感性敏感 用途注入所有沙箱的通用环境变量
环境变量GRASP_AGENT_TIMEOUT_SEC YAML 路径sandbox.agent_chat_timeout_seconds 类型integer 默认值未设置 敏感性公开 用途已废弃并忽略，Agent 回合不再有单轮总时限。节点总时限在画布节点上配置
环境变量GRASP_CHAT_IDLE_SEC YAML 路径sandbox.chat_idle_timeout_seconds 类型integer 默认值1200 敏感性公开 用途Agent 无动作时限秒数，既无输出也无 CPU/IO 活动这么久，先续跑一次，仍无活动则中断本轮。设置后设置页只读
环境变量GRASP_AGENT_NODE_HARD_CAP_HOURS YAML 路径sandbox.agent_node_hard_cap_hours 类型integer 默认值24 敏感性公开 用途未在画布配置总时限的 Agent 节点的兜底上限（小时）
环境变量GRASP_SANDBOX_MAX_ATTEMPTS YAML 路径sandbox.sandbox_max_attempts 类型integer 默认值3 敏感性公开 用途可重试沙箱故障的最大尝试次数
环境变量GRASP_SANDBOX_RETRY_BACKOFF_SEC YAML 路径sandbox.sandbox_retry_backoff_seconds 类型integer 默认值2 敏感性公开 用途沙箱重试基础退避秒数
环境变量GRASP_SANDBOX_CREATE_TIMEOUT_SEC YAML 路径sandbox.sandbox_create_timeout_seconds 类型integer 默认值1200 敏感性公开 用途等待沙箱就绪的超时秒数
环境变量GRASP_SANDBOX_MEMORY_TRIM_IDLE_MIN YAML 路径sandbox.memory_trim_idle_minutes 类型integer 默认值10 敏感性公开 用途E2B 沙箱模型回合结束多少分钟后首次清理页面缓存并整理内存，把内存还给主机。负数关闭
环境变量GRASP_SANDBOX_MEMORY_TRIM_INTERVAL_MIN YAML 路径sandbox.memory_trim_interval_minutes 类型integer 默认值30 敏感性公开 用途E2B 沙箱持续空闲时再次清理的间隔分钟数
环境变量GRASP_SANDBOX_MEMORY_TRIM_MIN_CACHE_MB YAML 路径sandbox.memory_trim_min_cache_mb 类型integer 默认值1024 敏感性公开 用途沙箱页面缓存低于该值（MiB）时跳过清理
环境变量GRASP_SANDBOX_MEMORY_MB YAML 路径sandbox.sandbox_memory_mb 类型integer 默认值0 敏感性公开 用途沙箱内存覆盖（MiB）。0 跟随网关/模板，非零至少 1024，E2B 必须匹配模板。环境变量覆盖并锁定设置页
环境变量GRASP_SANDBOX_WORK_DIR YAML 路径sandbox.work_dir 类型path 默认值未设置 敏感性公开 用途ConfigHome 宿主工作目录
环境变量GRASP_SANDBOX_RUNTIME_BUNDLE YAML 路径sandbox.runtime_bundle 类型path 默认值/app/sandbox-runtime/sandbox-runtime.tgz 敏感性公开 用途下发给沙箱的运行时包（scripts/build-sandbox-runtime.sh 构建）
环境变量GRASP_AUTH_SESSION_TTL YAML 路径auth.session_ttl 类型duration 默认值168h 敏感性公开 用途会话有效期
环境变量GRASP_AUTH_USERS YAML 路径auth.users 类型YAML/JSON 默认值未设置 敏感性敏感 用途静态账号数组。非本地部署必须显式配置
环境变量GRASP_SECRETS_KEY YAML 路径security.secrets_key 类型string 默认值未设置 敏感性敏感 用途固定的凭据加密主密钥（base64 编码的 32 字节）。非 production 的 SQLite 文件部署可在数据库旁自动生成 secrets.key，其他部署需显式提供
环境变量GRASP_STORAGE_DRIVER YAML 路径storage.driver 类型enum 默认值local 敏感性公开 用途附件存储驱动，local（预留 cos）
环境变量GRASP_MAX_FILE_BYTES YAML 路径storage.max_file_bytes 类型int 默认值134217728 敏感性公开 用途Agent 单文件导入大小上限（字节）
环境变量GRASP_BLOBS_ROOT YAML 路径storage.blobs_root 类型path 默认值data/blobs 敏感性公开 用途本地附件 blob 根目录
环境变量GRASP_SOLO_BACKUP_DIR YAML 路径solo_backup.local_dir 类型path 默认值data/solo-backups 敏感性公开 用途未配置 S3 时，沙箱回收时的工作区备份目录
环境变量GRASP_SOLO_BACKUP_MAX_BYTES YAML 路径solo_backup.max_bytes 类型int 默认值4294967296 敏感性公开 用途单个沙箱工作区压缩备份上限（字节）。超出则不能停止
环境变量GRASP_SOLO_BACKUP_KEEP YAML 路径solo_backup.keep 类型int 默认值1 敏感性公开 用途每个沙箱保留的成功恢复点数量，文件备份和 E2B 快照共用。新保存成功后清理旧版本
环境变量GRASP_SOLO_BACKUP_S3_ENDPOINT YAML 路径solo_backup.s3.endpoint 类型URL 默认值未设置 敏感性公开 用途S3 兼容服务地址。留空使用 region 对应的 AWS 地址
环境变量GRASP_SOLO_BACKUP_S3_REGION YAML 路径solo_backup.s3.region 类型string 默认值us-east-1 敏感性公开 用途S3 区域
环境变量GRASP_SOLO_BACKUP_S3_BUCKET YAML 路径solo_backup.s3.bucket 类型string 默认值未设置 敏感性公开 用途设置后沙箱工作区备份写入该 S3 桶，否则写本地目录
环境变量GRASP_SOLO_BACKUP_S3_PREFIX YAML 路径solo_backup.s3.prefix 类型string 默认值未设置 敏感性公开 用途S3 对象键前缀
环境变量GRASP_SOLO_BACKUP_S3_ACCESS_KEY_ID YAML 路径solo_backup.s3.access_key_id 类型string 默认值未设置 敏感性敏感 用途S3 访问密钥 ID
环境变量GRASP_SOLO_BACKUP_S3_SECRET_ACCESS_KEY YAML 路径solo_backup.s3.secret_access_key 类型string 默认值未设置 敏感性敏感 用途S3 访问密钥
环境变量GRASP_SOLO_BACKUP_S3_PATH_STYLE YAML 路径solo_backup.s3.path_style 类型boolean 默认值false 敏感性公开 用途使用路径式桶地址（MinIO 等自托管服务通常需要）
环境变量GRASP_GITHUB_OAUTH_CLIENT_ID YAML 路径github.oauth_client_id 类型string 默认值未设置 敏感性公开 用途GitHub OAuth App 的 Client ID（需勾选 Enable Device Flow）。设置后工作区可用「用 GitHub 登录」添加 github.com 凭据，不需要 client secret
环境变量GRASP_CODEX_LOGIN_REFRESH_LEAD YAML 路径codex_login.refresh_lead 类型duration 默认值96h 敏感性公开 用途Codex ChatGPT 登录在 access token 到期前多久由平台续期
环境变量GRASP_CODEX_LOGIN_CHECK_INTERVAL YAML 路径codex_login.check_interval 类型duration 默认值10m 敏感性公开 用途平台检查 Codex 登录是否需要续期的间隔
环境变量GRASP_SSH_GATEWAY_ENABLED YAML 路径ssh_gateway.enabled 类型boolean 默认值false 敏感性公开 用途开启内置 SSH 网关，让本地 VS Code / Cursor 等 IDE 通过 Remote-SSH 连接沙箱（用户名 sbx-<沙箱 ID>，在设置页登记公钥）
环境变量GRASP_SSH_GATEWAY_LISTEN YAML 路径ssh_gateway.listen 类型host:port 默认值:2222 敏感性公开 用途SSH 网关监听地址。需要在部署中对外开放这个 TCP 端口
环境变量GRASP_SSH_GATEWAY_PUBLIC_HOST YAML 路径ssh_gateway.public_host 类型string 默认值未设置 敏感性公开 用途用户 ~/.ssh/config 里填写的网关主机名。留空使用浏览器访问 Grasp 的主机名
环境变量GRASP_SSH_GATEWAY_PUBLIC_PORT YAML 路径ssh_gateway.public_port 类型integer 默认值listen port 敏感性公开 用途用户连接的网关端口（端口映射或负载均衡改了端口时设置）
环境变量GRASP_SSH_GATEWAY_HOST_KEY_PATH YAML 路径ssh_gateway.host_key_path 类型path 默认值data/ssh-gateway/host_ed25519_key 敏感性敏感 用途网关主机私钥路径，首次启动自动生成。必须放在持久卷上并由所有副本共享，否则客户端会提示主机密钥变更
环境变量GRASP_SSH_GATEWAY_MAX_CONNS YAML 路径ssh_gateway.max_conns 类型integer 默认值200 敏感性公开 用途网关同时连接数上限
环境变量GRASP_SSH_GATEWAY_MAX_CONNS_PER_SANDBOX YAML 路径ssh_gateway.max_conns_per_sandbox 类型integer 默认值10 敏感性公开 用途单个沙箱同时连接数上限
环境变量GRASP_SSH_GATEWAY_ADMINS_ONLY YAML 路径ssh_gateway.admins_only 类型boolean 默认值false 敏感性公开 用途仅允许管理员账号通过 SSH 网关连接。关闭时 Solo 会话的所有者可以进入自己的沙箱，工作流等其他沙箱只对管理员开放
环境变量GRASP_CODEX_LOGIN_AUTH_BASE_URL YAML 路径codex_login.auth_base_url 类型URL 默认值https://auth.openai.com 敏感性公开 用途OpenAI 登录服务地址，用于 Codex 登录续期和设备码登录。请求遵循 HTTPS_PROXY
