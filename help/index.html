开始使用

  • 快速开始

    →

    用 Docker Compose 启动本地演示，并检查 Grasp 和沙箱网关是否就绪。

  • 首次运行

    →

    配置凭据和模型组，选择 Agent，跑通一次 Solo 或默认工作流。

  • 核心概念

    →

    理解 Agent、模型组、运行、人工门禁、沙箱和产物之间的关系。

使用 Grasp

  • Solo 会话

    →

    打开会话、切换模型、查看预览，并在停止后恢复沙箱。

  • 工作流

    →

    用画布连接 Agent 节点与人工门禁，发布后启动、查看结果并处理待办。

  • 模型组与智能体

    →

    了解账号、编码工具、模型组和 Agent 的绑定关系，核对一次对话的实际模型。

  • 仓库与 Git 授权

    →

    登记仓库，为私有克隆和推送配置授权，并核对运行采用的分支和提交身份。

  • 常规设置

    →

    查看每个界面字段的默认值、影响范围、生效时机和验证方式。

  • 本地 IDE

    →

    启用 SSH 网关，登记公钥并从桌面 IDE 或终端连接。

部署与配置

  • 部署配置

    →

    选择 Docker、Kubernetes 或 E2B 后端，掌握配置入口、覆盖顺序和生效时机。

  • 配置项索引

    →

    按配置名查找 Grasp 环境变量、YAML 键、默认值与用途。

  • 网关与预览

    →

    核对网关连接、后端选择与预览策略，连接本地 IDE 或排查启动失败。

  • 网关参数

    →

    查询 Gateway 公共字段、Docker、Kubernetes、E2B 与沙箱运行时变量的默认值和影响。

  • 沙箱生命周期

    →

    比较三个后端的空闲回收、停止、恢复、容量和清理行为。

排查与贡献

  • 常见问题

    →

    按失败的阶段排查凭据、克隆、沙箱容量、预览和配置未生效。

  • 贡献

    →

    如何为 Grasp 做贡献；指向仓库贡献指南。
