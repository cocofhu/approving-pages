Gateway and sandbox configuration index

Look up defaults and effects for gateway, Docker, Kubernetes, E2B, and sandbox runtime settings.

On this page
  • Gateway common settings
  • Docker settings
  • Kubernetes settings
  • E2B settings
  • Sandbox runtime variables

Restart the gateway after changing its configuration and verify with a new test environment. Choose the backend section that matches driver. Time uses seconds, memory uses MiB, and disk uses GiB. See the configuration index for Grasp keys and Gateway and previews for setup.

Gateway common settings

YAML key Environment variable Default Effect
YAML keydriver Environment variableSBGW_DRIVER Defaultdocker EffectSelects docker, kubernetes, or e2b. The environment and file must select the same backend.
YAML keyserver.listen Environment variableSBGW_LISTEN Default:8080 EffectAddress where the gateway API listens.
YAML keyserver.finalizeTimeoutSeconds Environment variableSBGW_FINALIZE_TIMEOUT_SEC Default1200 EffectHow long a create or reinstall can wait for readiness.
YAML keydatabase.driver Environment variableSBGW_DB_DRIVER Defaultsqlite EffectChoose sqlite, mysql, or postgres.
YAML keydatabase.path Environment variableSBGW_DB_PATH Defaultgateway.db EffectPersistent SQLite file.
YAML keydatabase.dsn Environment variableSBGW_DB_DSN DefaultUnset EffectRequired for PostgreSQL. MySQL uses the DSN when set or the individual fields below.
YAML keydatabase.host / database.port Environment variableSBGW_DB_HOST / SBGW_DB_PORT DefaultUnset / 0 (connects on 3306) EffectMySQL host and port.
YAML keydatabase.user / database.password / database.name Environment variableSBGW_DB_USER / SBGW_DB_PASSWORD / SBGW_DB_NAME DefaultUnset EffectMySQL credentials and database name.
YAML keydatabase.params Environment variable— DefaultUnset EffectMySQL parameters. Defaults add charset=utf8mb4&parseTime=True&loc=Local.
YAML keyauth.apiKeys Environment variableSBGW_API_KEYS Default[] EffectBearer API keys. Separate environment values with commas. An empty list disables v1 authentication and prevents v2 transport.
YAML keyorphanGC.enabled Environment variableSBGW_ORPHAN_GC_ENABLED Defaultfalse EffectRemove workloads from this deployment that have no database record.
YAML keyorphanGC.intervalSeconds Environment variableSBGW_ORPHAN_GC_INTERVAL_SEC Default300 EffectInterval between orphan scans.
YAML keyorphanGC.minAgeSeconds Environment variableSBGW_ORPHAN_GC_MIN_AGE_SEC Default600 EffectMinimum age before cleanup. Use 0 to remove the age limit.
YAML keyports.session / ports.codeServer / ports.ssh Environment variable— Default8765 / 8744 / 22 EffectSession, IDE, and SSH ports.
YAML keyports.cdp / ports.novnc Environment variable— Default9222 / 6080 EffectInternal ports. Docker hosts and Kubernetes load balancers keep them private.
YAML keyports.app Environment variable— DefaultSee the backend example EffectAdditional application ports.
YAML key— Environment variableSBGW_LOG_LEVEL Defaultinfo EffectGateway logging level.
YAML key— Environment variableSBGW_LOG_PRETTY Defaultfalse EffectEnable human-readable gateway logging.

Docker settings

YAML key Environment variable Default Effect
YAML keyimage Environment variableSBGW_DOCKER_IMAGE Defaultuniversal-sandbox:local EffectOCI image for new Docker sandboxes.
YAML keybindIP Environment variableSBGW_DOCKER_BIND_IP Default127.0.0.1 EffectHost address where Docker publishes ports.
YAML keynetwork Environment variableSBGW_DOCKER_NETWORK DefaultUnset EffectDocker network to attach to.
YAML keynamePrefix / shmSize Environment variable— Defaultsbx- / 1g EffectContainer name prefix and shared memory size.
YAML keyresources.default Environment variable— DefaultCPU 0、memory 0、disk 0 EffectUsed when the request omits resources. 0 means unlimited. Fields are cpuCores, memoryMB, and diskGi.
YAML keyresources.max Environment variable— DefaultCPU 8、memory 16384、disk 500 EffectRequest limits. The Docker disk value does not create a storage quota.
YAML keyprofiles Environment variable— Default{} EffectOptional map of environment names to OCI images for named Grasp connections.

Kubernetes settings

YAML key Environment variable Default Effect
YAML keyimage Environment variableSBGW_K8S_IMAGE Defaultuniversal-sandbox:local EffectOCI image that cluster nodes can pull.
YAML keyinCluster Environment variableSBGW_K8S_IN_CLUSTER Defaultfalse EffectUse the pod service account.
YAML keykubeconfig Environment variableSBGW_K8S_KUBECONFIG DefaultUnset EffectBlank uses standard kubeconfig or in-cluster discovery.
YAML keynamespace Environment variableSBGW_K8S_NAMESPACE Defaultsandboxes EffectNamespace for sandbox resources.
YAML keynamePrefix Environment variable— Defaultsbx- EffectPrefix used to name workloads.
YAML keystorageClass Environment variableSBGW_K8S_STORAGE_CLASS DefaultUnset EffectBlank uses the cluster default storage class.
YAML keypvcAnnotations Environment variable— Default{} EffectAnnotations on newly created PVCs.
YAML keyimagePullSecret Environment variable— DefaultUnset EffectName of a private registry secret.
YAML keyimagePullPolicy Environment variableSBGW_K8S_IMAGE_PULL_POLICY DefaultIfNotPresent EffectChoose Always, IfNotPresent, or Never.
YAML keyenableLoadBalancer Environment variableSBGW_K8S_ENABLE_LB Defaulttrue EffectCreate a load balancer Service for exposed ports.
YAML keyresources.default / resources.max Environment variable— Default2/4096/25 / 8/16384/500 EffectDefault and maximum CPU, memory, and PVC size. Fields are cpuCores, memoryMB, and diskGi.
YAML keycpuRequestCores / memoryRequestMB Environment variable— Default0.25 / 512 EffectFixed scheduling requests take precedence. Set a field to 0 to use its ratio.
YAML keycpuRequestRatio / memoryRequestRatio Environment variable— Default0.25 / 0.25 EffectScheduling request equals limit multiplied by this ratio, in (0, 1]. The driver enforces minimum requests.
YAML keyprofiles Environment variable— Default{} EffectOptional map of environment names to OCI images.

E2B settings

YAML key Environment variable Default Effect
YAML keyapiURL Environment variableSBGW_E2B_API_URL DefaultRequired, no default EffectProvider control API origin. Use your self-hosted address or https://api.e2b.app for the cloud service.
YAML keysandboxURL Environment variableSBGW_E2B_SANDBOX_URL DefaultUnset EffectSelf-hosted sandbox proxy origin. Blank uses the hostname returned for each sandbox. A missing returned hostname causes an error.
YAML keyapiKey Environment variableSBGW_E2B_API_KEY DefaultRequired EffectProvider API key. Prefer passing it through the environment.
YAML keyownerID Environment variableSBGW_E2B_OWNER_ID DefaultRequired EffectStable, unique deployment identifier for scoping resources.
YAML keystateDir Environment variableSBGW_E2B_STATE_DIR DefaultRequired absolute path other than / EffectPersistent private state used to recover gateway connections.
YAML keybootTimeoutSeconds Environment variableSBGW_E2B_BOOT_TIMEOUT_SEC Default600 EffectDeadline for booting a guest and establishing private readiness.
YAML keyleaseSeconds Environment variableSBGW_E2B_LEASE_SEC Default3600 EffectRequested provider lease in seconds. Minimum 30.
YAML keyrenewIntervalSeconds Environment variableSBGW_E2B_RENEW_INTERVAL_SEC Default300 EffectLease renewal interval. Must be positive and less than half the lease.
YAML keyautoPause Environment variableSBGW_E2B_AUTO_PAUSE Defaulttrue EffectPause a new guest at lease expiry. An explicit delete still destroys it.
YAML keytemplates Environment variable— DefaultRequired, no built-in template EffectMap a name to templateID, cpuCores, memoryMB, and diskGi.
YAML keydefaultTemplate Environment variable— DefaultAutomatic for one template, required for multiple EffectChoose an existing name from templates.

Sandbox runtime variables

Runtime variable Standalone default Source and effect
Runtime variableGRASP_RUNTIME_URL Standalone defaultRequired to boot, no default Source and effectGrasp provides the runtime bundle download URL.
Runtime variableSANDBOX_INJECT / SANDBOX_INJECT_HEADERS Standalone defaultUnset Source and effectGrasp supplies the configuration bundle and scoped download authorization.
Runtime variableWORKSPACE_DIR Standalone default/root/workspace Source and effectCode directory inside the sandbox. Grasp’s sandbox.work_dir configures host-side staging.
Runtime variableROOT_PASSWORD Standalone defaulttoor Source and effectGrasp supplies the password for managed sandboxes. The standalone default applies when running the image by itself.
Runtime variableSSH_KEY Standalone defaultUnset Source and effectOptional SSH public key.
Runtime variableCODE_SERVER_PORT Standalone default8744 Source and effectBrowser IDE listen port.
Runtime variableAGENT_PROVIDER Standalone defaultcursor Source and effectGrasp sets the coding tool for the agent. Gateway driver selects the sandbox backend.
Runtime variableACP_BRIDGE_PORT Standalone default8765 Source and effectAgent session service port.
Runtime variableACP_BRIDGE_PASSWORD Standalone defaultUnset Source and effectGrasp supplies the session authentication password at creation.
Runtime variableSKIP_INNER_DOCKER Standalone default0, start the inner Docker daemon Source and effectSet to 1 to skip starting the inner Docker daemon.
Runtime variableINNER_DOCKER_STORAGE_DRIVER Standalone defaultvfs Source and effectStorage driver used by the inner Docker daemon.
Runtime variablePREVIEW_DIRECT / PREVIEW_PORT Standalone defaultUnset Source and effectDirect preview configuration and app port injected according to the preview policy.
