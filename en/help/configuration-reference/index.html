Deployment and configuration explains where to set each type of option and how to verify it. General settings covers fields available in the application, including the YAML-only deployment keys for capacity and idle reclaim.

Gateway, templates, and sandbox runtime

Browse the gateway option index by backend. Use the full deployment reference for Docker, Kubernetes, E2B, gateway, and sandbox runtime settings. The gateway guide explains the transport and preview choices.
